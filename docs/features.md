# Features

## User-Facing Features

- Clear hero section with headline, subheadline, and dual CTAs
- Product dashboard preview showing KPIs, AI summary, workflows, and document search
- Feature grid explaining six core product capabilities
- Pricing cards for Starter, Pro, and Enterprise plans
- Customer testimonials with star ratings
- FAQ accordion with common SaaS buyer questions
- Final CTA section encouraging trial signup or demo booking
- Responsive layout from mobile to desktop

## UI Features

- Premium dark theme with blue, purple, and cyan accents
- Glassmorphism cards with subtle borders and backdrop blur
- Gradient text and animated background orbs in the hero
- Framer Motion scroll and entrance animations
- Pure CSS/Tailwind dashboard mockup (no image dependencies)
- Highlighted Pro pricing card with "Most Popular" badge
- Mobile navigation with slide-down menu
- Smooth scroll between page sections

## Developer Features

- Next.js App Router with TypeScript
- Reusable UI components (Button, Card, Badge, Section)
- Static data files for features, pricing, testimonials, and FAQs
- `cn()` utility for conditional class merging
- Organized component structure (layout, sections, ui)
- SEO metadata and Open Graph tags in root layout
- Environment variable support for site URL

## Conversion Features

- Repeated CTA buttons ("Start Free Trial", "View Demo", "Book a Demo")
- Trust-building logo cloud section
- Social proof in hero (team count, ratings, metrics)
- Testimonials from fictional B2B personas
- FAQ addressing security, trials, and team usage
- Pricing transparency with free trial messaging
- Final CTA with trial terms and security certification note
