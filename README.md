## Project Overview

**NeuroFlow AI** is a fictional AI SaaS product designed for business teams that want to automate workflows, search internal knowledge, summarize documents, and improve productivity with AI. This repository contains a complete marketing landing page that presents the product with clarity, credibility, and conversion-focused design.

## Business Goal

The landing page helps AI startups explain their value proposition quickly, build trust with potential customers, and convert visitors into free trial signups or demo requests. Every section is structured to reduce friction and guide visitors toward action.

## Key Features

- Modern AI SaaS landing page with premium dark aesthetic
- Responsive desktop and mobile layout
- Animated sections with Framer Motion
- Reusable component architecture
- Product dashboard mockup built with Tailwind CSS
- Pricing cards with highlighted Pro plan
- B2B-style testimonials
- FAQ accordion section
- Conversion-focused CTA sections
- SEO-friendly page structure
- Clean Tailwind CSS styling with glassmorphism
